# Contributing

This is a personal portfolio, not a project seeking contributors. It is public
so the engineering can be read, not so the design can be changed.

**Pull requests changing content, copy, photography or visual design will be
closed.** Those are founder-approved and frozen — the reasoning is in
[CLAUDE.md](CLAUDE.md) §1.

If you have found a genuine defect — a broken link, a failing gate, an
accessibility problem, a stale statement in the docs — an issue is welcome and
appreciated. For anything security-related, read [SECURITY.md](SECURITY.md)
first; do not open a public issue for something exploitable.

If you are here to see how the site is built, the useful entry points are:

| File                                       | What it holds                                  |
| ------------------------------------------ | ---------------------------------------------- |
| [CLAUDE.md](CLAUDE.md)                     | The standing rules, the budgets, and the traps |
| [BACKLOG.md](BACKLOG.md)                   | What was built, in order, with commit SHAs     |
| [QUESTIONS.md](QUESTIONS.md)               | Every decision, its ruling, and the date       |
| [AUDIT-2026-08-14.md](AUDIT-2026-08-14.md) | The most recent full audit                     |

The code carries no licence, which means all rights are reserved by default.
Read it, learn from it; do not reuse the content, photography or copy.
